about=
    === INSTRUKCJA (PL) ===
    Wtyczka konwertuje pliki PDF do GeoTIFF bezstratnie, przez gdal_translate.
    1. Uruchomienie: ikona na pasku narzędzi albo menu Wtyczki → PDF -> TIFF.
    2. "Katalog PDF" – katalog z plikami PDF do konwersji.
    3. "Katalog TIFF" – gdzie zapisać pliki TIFF (puste = obok plików PDF).
    4. "gdal_translate" – ścieżka do gdal_translate.exe (domyślnie wykrywana: instancja QGIS, PATH, C:\QGIS\bin, C:\OSGeo4W\bin, C:\Program Files\QGIS*).
    5. "DPI" – 200 dla PDF rastrowych (bez utraty jakości).
    6. Opcje: "Pomijaj istniejące TIFF", "Podkatalogi" (zachowuje strukturę katalogów).
    7. Grupa "Strony PDF" (PDF wielostronicowe):
       - "Tylko rysunki (domyślnie)" – zapisuje strony większe niż wybrany format (A3 = większe niż A4), czyli pomija opisówki A4 i inne strony tekstowe,
       - "Wszystkie strony" – każda strona PDF-a,
       - "Wskazane strony" – lista, np. 1,3,5-8.
       Dodatkowo "Min. format rysunku" (A4 = bez filtra formatu) oraz "Min. pokrycie tuszem (procent)" (0 = filtr wyłączony, odsiewa strony puste).
       Nazwy plików: PDF jednostronicowy → nazwa.tif, PDF wielostronicowy → nazwa_p01.tif, nazwa_p02.tif, ...
       Każda decyzja (która strona i dlaczego) jest zapisywana w logu.
    8. START – górny pasek pokazuje bieżący plik, dolny postęp całości; log tekstowy niżej. STOP przerywa pracę (kończy bieżący proces GDAL).
    Ustawienia pól są zapamiętywane w profilu QGIS.
    Wywoływana komenda:
      gdal_translate --config GDAL_PDF_DPI <DPI> -of GTiff -co COMPRESS=DEFLATE -co PREDICTOR=2 -co TILED=YES -co BIGTIFF=IF_SAFER "wejście.pdf" "wyjście.tif"
    Algorytm w Panelu przetwarzania: "Konwertuj PDF do TIFF (bezstratnie)" (grupa Konwersja PDF) – można go użyć w modelach i w qgis_process. Ma te same opcje wyboru stron (tryb, lista stron, min. format, min. tusz).
    Jak sprawdzić DPI PDF-a: gdalinfo "plik.pdf" (natywne DPI = szerokość_px / szerokość_strony_w_calach).
    === USER GUIDE (EN) ===
    The plugin converts PDF files to GeoTIFF losslessly through gdal_translate.
    1. Start: toolbar icon or menu Plugins → PDF -> TIFF.
    2. "Katalog PDF" – folder with PDF files.
    3. "Katalog TIFF" – output folder (empty = next to the PDFs).
    4. "gdal_translate" – path to gdal_translate.exe (auto-detected: current QGIS install, PATH, C:\QGIS\bin, C:\OSGeo4W\bin, C:\Program Files\QGIS*).
    5. "DPI" – 200 for raster PDFs (no quality loss).
    6. Options: "Pomijaj istniejące TIFF" (skip existing), "Podkatalogi" (keep folder structure).
    7. "Strony PDF" group (multipage PDFs):
       - "Tylko rysunki (domyślnie)" – saves pages larger than the chosen sheet format (A3 = larger than A4), so A4 description pages are skipped,
       - "Wszystkie strony" – every page,
       - "Wskazane strony" – a list, e.g. 1,3,5-8.
       Plus "Min. format rysunku" (A4 = no format filter) and "Min. pokrycie tuszem (procent)" (0 = filter off, drops nearly blank pages).
       File names: single-page PDF → name.tif, multipage PDF → name_p01.tif, name_p02.tif, ...
       Every decision (which page and why) is written to the log.
    8. START – the upper bar is the current file, the lower one the overall progress, text log below; STOP aborts (kills the running GDAL process).
    Field values are remembered in the QGIS profile.
    Command used:
      gdal_translate --config GDAL_PDF_DPI <DPI> -of GTiff -co COMPRESS=DEFLATE -co PREDICTOR=2 -co TILED=YES -co BIGTIFF=IF_SAFER "input.pdf" "output.tif"
    Processing algorithm: "Konwertuj PDF do TIFF (bezstratnie)" (group "Konwersja PDF") – usable in models and qgis_process, with the same page-selection options (mode, page list, min. format, min. ink).
    Checking a PDF's DPI: gdalinfo "file.pdf" (native DPI = width_px / page_width_in_inches).

    1.1.0 - obsługa PDF wielostronicowych: strony odczytywane jako podzbiory GDAL ("PDF:numer:plik"), domyślny tryb "tylko rysunki" (strony większe niż wybrany format, np. Fixed enum type detection for Qt6 (QgsProcessingParameterNumber.Type.Integer, QgsProcessingParameterFile.Behavior.Folder/File) - works with QGIS 3.22+ and QGIS 4.x.

    1.0.1 - security fixes required by the QGIS plugin repository: gdal_translate is started via QProcess (argument list, no system shell, no subprocess module) and empty except/pass blocks were removed; no functional change.
    1.0.0 - pierwsza wersja: okno konwertera (katalog PDF/TIFF, gdal_translate, DPI, pomijanie istniejących, podkatalogi, dwa paski postępu, log, STOP), algorytm Processing, wykrywanie gdal_translate, zapamiętywanie ustawień.
    1.0.0 - first release: the converter window (PDF/TIFF folders, gdal_translate path, DPI, skip existing, subfolders, two progress bars, log, STOP), Processing algorithm, gdal_translate auto-detection, remembered settings.
